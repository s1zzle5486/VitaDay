# Time zone data

Generated from the local IANA time zone database 2026c (zone.tab and compiled zoneinfo). IANA tz database code/data are public domain except separately identified components, which are not included here. https://www.iana.org/time-zones

This compact derivative stores UTC offset transitions for 2025-01-01 through 2036-12-31, including daylight saving time, and country-to-zone choices. Future legal time-zone changes require rebuilding this data. The build script is tools/build_zones.py.
